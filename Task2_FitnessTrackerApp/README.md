# Fitness Tracker App

A simple fitness tracking app built with **SwiftUI**.
Developed as **Task 3** of the CodeAlpha App Development Internship.

## Features
- Manually log activities: type, date, steps, duration and calories burned
- **Dashboard** with today's progress bars for steps, calories and active time
- **7-day bar graph** with a Steps / Calories / Minutes switch, plus weekly total and daily average
- **History** tab with swipe-to-delete
- Editable daily goals
- Data stored locally on the device (UserDefaults), no backend needed

## Tech Stack
- Swift, SwiftUI
- UserDefaults + Codable for local storage

## How to Run
1. Open the project in Xcode (iOS 16 or later)
2. Select a simulator or device
3. Press **Run** (⌘R)

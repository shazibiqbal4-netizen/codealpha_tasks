# LinguaLearn — Language Learning App

An interactive language learning app built with **SwiftUI**.
Developed as **Task 4** of the CodeAlpha App Development Internship.

## Features
- Languages: Spanish, French and German
- Categories: Vocabulary, Phrases and Grammar
- **Daily Lesson** with 5 new items every day
- Flashcards with translations and pronunciation guides
- **Listen** button using text-to-speech (AVFoundation)
- Quizzes per category and a Mixed Test, with best scores saved
- Progress tracking of learned items
- Data stored locally on the device

## Tech Stack
- Swift, SwiftUI, AVFoundation
- UserDefaults for local storage

## How to Run
1. Open the project in Xcode (iOS 16 or later)
2. Select a simulator or device
3. Press **Run** (⌘R)

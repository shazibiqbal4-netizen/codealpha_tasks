# CodeAlpha Tasks — App Development Internship

Projects completed during the **CodeAlpha App Development Internship** (10 Nov – 10 Dec 2026), built with **Swift** and **SwiftUI**.

| Task | Project | Description |
|------|---------|-------------|
| 1 | [Flashcard Quiz App](Task1_FlashcardQuizApp) | Flip-card study app with add, edit and delete |
| 2 | [Random Quote Generator](Task2_RandomQuoteApp) | Random quotes with a "New Quote" button |
| 3 | [Fitness Tracker App](Task3_FitnessTrackerApp) | Log activities, dashboard and 7-day graph |
| 4 | [Language Learning App](Task4_LanguageLearningApp) | Spanish, French and German lessons, flashcards and quizzes |

## How to Run
1. Create a new iOS App project in Xcode (Interface: SwiftUI, iOS 16+)
2. Delete the template's default `App` and `ContentView` files
3. Add the `.swift` files from the task's `Sources` folder
4. Press **Run** (⌘R)
